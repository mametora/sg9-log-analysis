# RomRaiderデスクトップアプリ

このリポジトリの解析処理を利用する、ローカル専用のデスクトップアプリです。
CSVや分析状態をサーバーへ送信する機能はありません。

## 起動

```sh
uv sync --extra desktop
uv run --extra desktop python -m src.desktop
```

CSVを引数にして開くこともできます。

```sh
uv run --extra desktop python -m src.desktop data/raw/*.csv
```

macOSでは、以下でアイコンから起動するためのランチャーを作成できます。

```sh
uv run --extra desktop python scripts/create_macos_app.py
```

`output/desktop/RomRaider Log Analyzer.app` をFinderで開いてください。
この `.app` は、このチェックアウトと `.venv` を使うローカルランチャーです。
単体配布用ではなく、リポジトリを移動した場合は作り直す必要があります。
起動時の記録は `.cache/desktop/launch.log` に保存します。

## 基本操作

1. 「ログを追加」またはCSVのドラッグで読み込みます。ログ一覧のチェックで表示を切り替え、ダブルクリックで表示名を変更できます。
2. グラフ見出しの「グラフ1」などをクリックして対象を選び、左の項目一覧で表示する項目を変更します。
3. グラフを重ねる場合は同じグラフに複数項目を追加します。個別に表示する場合は「新しいグラフ」で追加します。
4. 「開始」「終了」を入力して「範囲を適用」を押すか、下の概観にある選択枠の左右端を動かします。枠全体のドラッグで、幅を保って範囲を移動できます。
5. グラフ上のドラッグでも拡大できます。「全体表示」「前の範囲」で戻れます。グラフの右クリックメニューから移動モードも選択できます。
6. 右の系列一覧で対象を選び、左右軸・色・統計線を設定します。軸の割り当てと色は、同じグラフ内の同じ項目についてログ間で共通です。
7. 「2列に並べる」、見出しの上下ボタン、設定欄の表示切り替えで配置を調整できます。

縦軸は初期状態で表示範囲に応じて自動調整されます。同じ項目を別ログと重ねると同じ目盛りを使用します。
異なる単位の項目は、右軸への割り当てか別グラフで表示してください。単位の自動変換は行いません。

## 別ログとの比較

- 複数CSVを追加すると、各グラフの項目が各ログから表示されます。存在しない項目は描画されません。
- 項目ごとの色は共通で、ログごとに実線・破線・点線などを使います。4種類を超えると線種は繰り返します。凡例でもログ名を確認してください。
- 初期状態は各ログの先頭記録を0秒とする経過時刻です。
- 左でログを選び、基準にしたい元ログの経過秒を入力して「この時刻を0秒にする」を押します。
- グラフ上でC1を合わせてから「C1位置を基準点にする」を使うこともできます。ログごとに対応する場面を基準点に指定してください。
- 比較時刻は `元ログの経過秒 − 基準点` です。基準点より前の時刻は負になります。
- 時間合わせは表示位置だけを変更し、元のCSVや記録時刻は変更しません。変更後は全体表示に戻ります。
- 注釈は比較時刻に固定されます。基準点を変更した場合は、必要に応じて注釈も調整してください。
- 「時間軸を連動」を解除すると、グラフごとに別の時間範囲を保持します。下部の範囲と概観は選択中のグラフが対象です。

## 統計とカーソル

- 最大・最小・平均・中央値の線を系列ごとに切り替えられます。
- 統計対象は選択範囲またはログ全体です。欠損・非有限値を除外し、有効データ数を表示します。
- 平均は記録値の算術平均です。時間による重み付けはしません。
- 表示を軽量化するために描画点を減らす場合でも、統計とCSV出力には元の記録値を使用します。
- クリックでC1、Shift+クリックでC2を移動します。縦線のドラッグや数値入力もできます。
- 値一覧にはC1・C2の近傍の記録値と差分を表示します。元ログの経過秒と単位はセルのツールチップで確認できます。
- カーソル値は補間しません。標準記録周期の約半分以内に有効な記録がない場合は `—` を表示します。
- 欠損値、時刻の重複・巻き戻り、大きな記録間隔（標準周期の5倍または0.5秒の大きい方を超える間隔）をまたぐ線は描きません。
- 時刻の巻き戻りがあるログは、同じ比較時刻に複数の記録が重なる場合があります。「詳細」で注意点を確認してください。

## 保存と出力

- **分析状態**：ログ参照、表示名、表示設定、時間合わせ、範囲、統計対象、カーソル、注釈をJSONに保存します。元CSV自体は含みません。
- 元CSVは保存先からの相対パスで参照します。見つからない場合は再選択できます。内容が保存時と異なる場合は確認を表示します。
- **プリセット**：グラフの項目・配置・色・軸・統計線を保存します。ログ固有のパス、基準点、選択範囲、注釈は含みません。
- 統計線のログ割り当ては読み込み順で対応します。初版ではローカルの `.local/desktop/presets/` に保存し、適用・上書き編集・複製・名前変更・削除ができます。
- **画像**：グラフ一覧をPNGで出力します。現在の範囲、凡例、統計線、注釈が反映されます。
- **区間CSV**：左で選択中のログについて、選択時間範囲の全記録項目を出力します。元の時刻列を保持し、先頭に比較時刻を追加します。途中で取得していない項目は空欄になります。
- 読み込んだ元ログへの上書きは拒否します。

## 検証

```sh
QT_QPA_PLATFORM=offscreen uv run --extra desktop python -m unittest discover -s tests -v
```

GUIの範囲選択・連動解除・時間合わせ・統計線更新に加え、保存形式、欠損区間、出力による元CSVの保護を確認します。

## 初版の範囲外

自動時間合わせ、条件の一致する区間の自動探索、ログ間の差分波形、単位変換、散布図、
計算式による項目追加、自動イベント検出、配布用の署名・公証・単独実行パッケージは後続の拡張候補です。
