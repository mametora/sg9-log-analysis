## 実行方法

リポジトリのルートで、モジュールとして起動します。

```sh
uv run python -m scripts.comparison_20260912.plot_split_160818
```

入力は既定で `~/Downloads/Logs/`、出力は `output/20260912/comparison/` です。
入力先を変える場合は `SG9_LOG_DIR` にディレクトリを指定できます。

```sh
SG9_LOG_DIR=/path/to/logs uv run python -m scripts.comparison_20260912.plot_mechanic_dual
```

入力CSVはリポジトリに含みません。描画にはmacOSのヒラギノフォントを使用します。
生成物はGit管理対象外です。分析記録は [MAF交換前後比較](../../docs/analysis/20260912/MAF交換前後比較.md) に保存し、スクリプトからは書き換えません。

| モジュール | 内容 |
|---|---|
| `compare` | 同じ運転条件の区分による旧集計。訂正前の交換区分を含む |
| `plot_today` | 当日のログ全体の旧描画。訂正前の交換区分を含む |
| `plot_split_160818` | 長い記録中断の前後を分けた区間別図 |
| `plot_mechanic` | 中断後の4項目を並べた共有用図 |
| `plot_mechanic_dual` | 中断後の回転数・MAFを重ねた2軸図 |
| `plot_pickups` | 指定した30秒区間の抜粋図 |

16:08:18開始ログは中断前後で交換前・交換後に分かれます。
`compare` と `plot_today` はログ全体を交換後としており、その結果を現在の交換前後比較の結論として使用しないでください。
区間の切り分けや確認時刻は、当時のユーザー説明に基づくものです。
